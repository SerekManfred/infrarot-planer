# backend

FastAPI-Anwendung: REST-API, Datenbankzugriff (PostgreSQL), KI-Anbindung für den Grundriss-Import und Exporte (PDF/Excel, später Word).

Die Berechnungen selbst liegen nicht hier, sondern im Modul `rechenkern/`. Konfiguration ausschließlich über Umgebungsvariablen.

Stand: Phase 0 – noch leer.
