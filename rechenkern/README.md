# rechenkern

Eigenständiges Python-Modul für die Fachberechnungen – ohne Abhängigkeiten zu Web-Framework oder Datenbank:

- Bauteile und U-Werte
- raumweise Heizlast (vereinfachtes Verfahren nach dem Prinzip der DIN EN 12831-1)
- später: Paneelauslegung, Variantenvergleich Infrarot/Wärmepumpe

Jede Funktion wird mit pytest getestet; Beispielrechnungen dienen als Testfälle.

Stand: Phase 0 – noch leer.
